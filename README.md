# Mubahat Visuals

A production-ready, responsive portfolio website for Mubahat Visuals.

## Included

- Dark cinematic design with a glass navigation bar
- UGC AI Ads listed first
- Responsive service, portfolio, process, about, FAQ, contact and footer sections
- Client photo retained in the navbar and About section
- Branded logo in the footer, About badge, favicon and social preview
- Working WhatsApp project enquiry form
- Portfolio data loaded from `data/projects.json`
- Pages CMS configuration for coding-free project updates
- Automatic GitHub Pages deployment workflow
- YouTube Unlisted, Vimeo and direct MP4/WebM playback support

## Local preview

Open the folder in VS Code and use **Live Server**. Do not double-click `index.html` directly because browsers may block loading `data/projects.json` from `file://` URLs.

## Website development service

The public site now includes **High-Converting Websites** as a service, a website-launch explainer, Smart Start vs Brand Launch guidance, and a detailed website requirements form that opens the completed brief in WhatsApp.

For static portfolio/landing/brochure websites, GitHub Pages can provide the hosting layer. Custom domains are purchased separately. E-commerce, accounts, databases, and server-side features require a suitable advanced hosting/backend setup.
